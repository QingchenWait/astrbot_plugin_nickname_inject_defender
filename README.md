# 昵称注入阻断器

用于阻止 AstrBot 的群聊中的**昵称注入**行为：例如，当 NapcatQQ/OneBot 消息中，“唤醒词只出现在用户昵称、引用昵称或 @ 昵称中、未出现在用户实际正文文本中” 时，阻止 AstrBot 继续调用 LLM。

## 配置

- `昵称黑名单列表来源`：选择 `继承自系统` 或 `手动设置`。
- `继承自系统`：每次处理消息时从 AstrBot 当前已加载的全部配置文件读取**唤醒词** ( `wake_prefix`)，包含默认配置和 WebUI 创建的多配置文件。
- `手动设置`：使用 `手动黑名单列表` 中填写的字符串列表。

## 行为

- 仅处理群消息。
- 以高优先级处理群消息；未命中阻断条件时不发送消息、不打印日志，让 AstrBot 正常继续。
- 若某个唤醒词仅出现在发送者昵称、被引用消息的发送者昵称或被 @ 用户昵称中，但未出现在用户正文文本中，则调用 `event.stop_event()` 截断后续插件、LLM 和回复流程。
- 只要用户正文文本包含任一已配置唤醒词，就不会阻断；包括昵称带唤醒词的用户正常带唤醒词发言，以及 A 引用或 @ 昵称带唤醒词的 B 时正文带唤醒词的情况。
- 用户正文文本只统计 OneBot 文本/Markdown 段，不把 `@` 段展示名和引用消息发送者昵称计入正文。
- 当 `@` 或 `reply` 消息段只包含 QQ/id 时，插件会通过 OneBot API 查询群成员信息或被引用消息发送者信息来补全昵称；查询失败时静默跳过该昵称来源。
- 截断时输出日志：`由于唤醒词 XXX 仅在用户昵称中存在，终止消息传递`。
